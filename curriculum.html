每一级对应一个阶段目标：入门编程 → GESP → CSP-J → CSP-S / NOIP → NOI / 省队。 大致判断一下自己所在的层级，再进入学习中心选择对应课程即可。

适合完全零基础或只做过少量图形化编程的同学。 目标是能独立写出带输入输出的简单 C++ / Python 程序， 熟悉 if / for / while 等基本语句，为后续算法打地基。

适合已经能写简单程序的同学。 目标是通过 GESP 2–3 级，能解决“模拟 + 枚举 + 简单数学”这一类基础信息学题目。

适合准备首次参加 CSP-J 的同学。 目标是掌握前缀和 / 差分 / 简单贪心 / BFS 等常见思路， 在 CSP-J 中稳住中上成绩，为进阶 CSP-S 做准备。

适合已经有一两次竞赛经验的同学。 目标是在 CSP-S / NOIP 中拿到有竞争力的成绩， 能独立完成中等难度的图论、DP 与数据结构题目。

适合已经在 CSP-S / NOIP 拿到高分的选手。 目标是系统梳理高阶图论、复杂 DP 与高级数据结构， 适应省队 / NOI 级别的训练与比赛强度。
